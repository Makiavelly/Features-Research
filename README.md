## Код, зависимости и инструкции

Папка [reviewer_repository](reviewer_repository/) содержит материалы для проверяющего.
Начните с [инструкции](reviewer_repository/README.md): там указаны зависимости,
получение данных, проверочные команды, повторное обучение и настройка собственного
API-ключа в `.env` через `ACCESS_TOKEN`.

Быстрая проверка сохранённых результатов без данных, GPU и API-ключа:

```bash
cd reviewer_repository
python verify_saved_results.py
```

Эта команда проверяет сохранённые метрики 21 метода и независимо пересчитывает
MAP по настоящим прогнозам трёх методов. Она не запускает обучение или модели.
Данные, обученные веса, окружения, кэши и секреты в поставку не включены.
Для точного исторического инференса всех моделей потребуются отдельные веса;
ограничения описаны в [VALIDATION.md](reviewer_repository/VALIDATION.md).

Корневой `.gitignore` разрешает эту папку, два итоговых отчёта и служебные
README/.gitignore. Новые локальные результаты исключаются правилами внутри
`reviewer_repository`. Старые файлы исследования остаются на диске, а прежние
коммиты сохраняются в истории Git.
