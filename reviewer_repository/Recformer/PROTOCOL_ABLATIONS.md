# Recformer: две раздельные абляции

Пользователь поручил2026-10-16 сначала проверить меньшийLR/warmup,
затем отдельно заморозку нижних слоёв. Все настройки закреплены до запуска.
Никакого обучения с нуля: обе модели независимо загружают тот же pretrained
checkpoint6ca01ee6ce48756e49b381da1fa6eedb8873cdeb6f96b13274e89a6b5884d022.
Не продолжают предыдущий fine-tuned checkpoint и не продолжают друг друга.

Общее: прежние10файлов small-v1,4804train/304val/250test,5000каталог,
256tokens,3attributes,50items,batch4/accum4,seed42,2+2полных эпохи,
тот же порядок trainстрок и dropout,weekly multi-positive fullsoftmax,
cache policy и оценка MAP@12. Старыйrun_small.py и результаты не меняются.

1. hm_recformer_small_low_lr_warmup_seed42_v1:
   все148110336параметров обучаются. ПиковыйLR1e-5 вместо5e-5.
   Первые100успешныхoptimizer updates: линейныйwarmup1%→100%, затем
   линейное снижение до0за1204плановыхupdates. AMPskips не двигаютschedule.
   LR иscheduler — совместное изменение; их эффекты отдельно не изолируются.
2. hm_recformer_small_freeze_lower6_seed42_v1:
   embeddings иencoder.layer[0:6] из12слоёв заморожены; верхние6обучаются.
   Прежний постоянныйLR5e-5, безwarmup/decay. Это проверка заморозки против
   прежнего полного дообучения, а не комбинация со способом1.
   Поведениеdropout сохраняется. SHA всех замороженных параметров должен
   совпасть до/после обучения; trainable counts сохраняются.

Два обучающих запуска идут последовательно; сначала оба завершают обучение
и выбор trainedcheckpoint только поvalidation, затем считаютсяtest обоих.
Zero-shot эпоха0 также допустима для validationвыбора в selection.json,
но лучший trainedcheckpoint сохраняется и оценивается отдельно для сравнения.
Zero-shot scoreматрицы должны точно совпасть со старым контролем.

После оценки независимый процесс повторяет полныйval/test обоих checkpoints
для каждого варианта. Сравниваются всеscores/top12/MAP, сохраняются хеши.
Отдельный новый отчёт reports/recformer_ablations_v1 сравнивает старые и новые
модели, кривые, lr, интервалы описательного paired-user bootstrap.
Не запускать новые настройки по увиденнымtest; одинseed/малыйtest остаются
ограничениями. Ориентир до часа на запуск; два запуска не идут одновременно.
